B10 [보너스: 정합성] CHECK 위반: 별점 6점, 존재하지 않는 날짜, 허용되지 않는 회원 상태
source: sql/05_bonus_integrity.sql

sqlite> INSERT INTO review (member_id, movie_id, rating, content, created_at)
   ...> VALUES (12, 1, 6, '별점 6점?', '2024-10-01 10:00:00');
Error (예상된 오류): CHECK constraint failed: rating BETWEEN 1 AND 5

sqlite> INSERT INTO movie (genre_id, title, release_date, running_time, country, director)
   ...> VALUES (2, '날짜 오류 영화', '2024-02-30', 100, '한국', '미상');
Error (예상된 오류): CHECK constraint failed: date(release_date, '+0 days') IS release_date

-- CHECK 를 date(x) = x 로 만들었다면 이 행은 통과했다 (date('2024-13-01') 이 NULL → CHECK 가 NULL 을 통과시킴).
-- IS 로 비교하도록 고쳐서 막힌다. '2024-02-30' 은 '+0 days' 수식어로 버전과 상관없이 막는다. 01_schema.sql 주석 참고
sqlite> INSERT INTO movie (genre_id, title, release_date, running_time, country, director)

Error (예상된 오류): CHECK constraint failed: date(release_date, '+0 days') IS release_date
